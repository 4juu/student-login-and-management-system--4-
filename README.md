## 📋 كيفية الاستخدام

### 1️⃣ تسجيل الدخول كأدمن
```
1. افتح الموقع
2. أدخل بريد الأدمن: mujtabahaitham@gmail.com
3. أدخل كلمة المرور: 0700234
4. اضغط "تسجيل الدخول"
```

### 2️⃣ إنشاء حساب تدريسي جديد
```
1. اضغط على تبويب "👨‍🏫 إدارة التدريسيين"
2. اضغط "إضافة تدريسي جديد"
3. أدخل:
   - الاسم الكامل
   - البريد الإلكتروني
   - كلمة المرور الأولية (6 أحرف على الأقل)
4. اضغط "إنشاء الحساب"
5. ✅ تم! يمكن للتدريسي تسجيل الدخول الآن
```

### ➕ تغيير كلمة مرور تدريسي (عند النسيان)
```
1. اضغط على تبويب "👨‍🏫 إدارة التدريسيين"
2. في صف التدريسي المطلوب، اضغط "تغيير الرمز"
3. أدخل كلمة المرور الجديدة (6 أحرف على الأقل)
4. اضغط "تغيير كلمة المرور"
5. ✅ ستظهر رسالة نجاح مع كلمة المرور الجديدة
6. احفظ كلمة المرور
7. أبلغ التدريسي بكلمة المرور الجديدة
8. ✅ التدريسي يسجل دخول بكلمة المرور الجديدة
```

### 🗑️ حذف حساب تدريسي
```
1. اضغط على تبويب "👨‍🏫 إدارة التدريسيين"
2. في صف التدريسي المطلوب، اضغط "حذف"
3. تأكيد الحذف
4. ⚠️ سيتم حذف الحساب وجميع البيانات نهائياً
5. ✅ تم الحذف
```

### 3️⃣ تسجيل الدخول كتدريسي
```
1. افتح الموقع
2. أدخل البريد الإلكتروني للتدريسي
```

### 4️⃣ استخدام النظام (للتدريسي)
```

├─ تبويب "📋 السجلات"
```

## 📊 السيناريوهات

### سيناريو 1: مدرسة مع عدة تدريسيين

```
الأدمن:
├─ ينشئ حساب للأستاذ أحمد (مادة الرياضيات)
├─ ينشئ حساب للأستاذة فاطمة (مادة العلوم)
└─ ينشئ حساب للأستاذ محمد (مادة اللغة العربية)

الأستاذ أحمد:
├─ يضيف طلاب صفه (30 طالب)
├─ ينشئ سجل كل يوم
├─ يسجل حضور الطلاب
└─ بياناته منفصلة تماماً

الأستاذة فاطمة:
├─ يضيف طلاب صفها (25 طالبة)
├─ ينشئ سجل كل يوم
├─ تسجل حضور الطالبات
└─ بياناتها منفصلة تماماً

النتيجة:
✅ كل تدريسي له بياناته الخاصة
✅ لا تداخل بين البيانات
✅ الأدمن يمكنه رؤية عدد التدريسيين
```

### سيناريو 2: تدريسي واحد - عدة مواد

```
الأستاذ خالد:
├─ يضيف طلاب المادة 1
├─ يضيف طلاب المادة 2
├─ ينشئ سجلات منفصلة:
│   ├─ سجل: "حضور رياضيات - الأحد"
│   ├─ سجل: "حضور فيزياء - الأحد"
│   └─ سجل: "اختبار رياضيات"
└─ يصدر كل سجل على حدة
```
